# JetaFX Regulation Web Application

A pixel-perfect Next.js web application implementing the JetaFX Regulation design specifications.

## 🌟 Key Features
- **Initial View**: Opens strictly showing the Hero Banner.
- **Scroll Reveal Animation**: Clicking the **"View our regulation"** button triggers a smooth animation revealing the **Licensing & Regulation**, **Key Facts**, and **FSC Verification** cards.
- **Visuals**:
  - Hero banner with background imagery and lighting.
  - Body container with deep obsidian/navy backdrop and light ray PNG effect.
  - Official FSC Mauritius public register links and verified details.
- **24/7 Cloud Availability**: Automatically built and published to GitHub Pages via GitHub Actions.

## 🚀 Live Link
- **GitHub Pages**: [https://signkipdesign-afk.github.io/jetafx/](https://signkipdesign-afk.github.io/jetafx/)

## 🛠️ Tech Stack
- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Deployment**: GitHub Pages (Static Export)

## 💻 Local Development
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
